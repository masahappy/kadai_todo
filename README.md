# AIToDo

AIを活用したタスク管理アプリです。

## 概要

AIToDoは、日々のタスクを効率的に管理するためのWebアプリケーションです。
「1dayモード」「1weekモード」「1monthモード」を切り替えて使えます。

- **1dayモード**：今日やることを、0〜24時の時間軸に並べて管理します。
- **1weekモード**：締切日つきの課題と今週の予定を管理します。未完了の課題と今週の予定を入力すると、AIが効率的なスケジュールを提案してくれます。
- **1monthモード**：1か月分の予定とタスクを、カレンダーで一覧・管理します。ページをめくるように、前の月・次の月へ移動できます。

ログイン機能により、ユーザーごとにタスク・予定を管理できます。1dayモードと1weekモードの課題は、完全に分かれて管理されます。1monthモードは、1day・1weekの課題も含めて、日付ごとにまとめて表示します。

## 機能

### 共通

- メールアドレス／パスワードによるログイン・新規登録・ログアウト
- ログイン後にモード（1day／1week／1month）を選択。画面上部のボタンで、いつでも切り替え可能
- 課題の追加・編集・削除・完了管理（ユーザーごとにSupabaseへ永続化）
- 右下の「＋」ボタンから、ポップアップで課題を追加
- カテゴリ別のタブで、課題をカテゴリごとに絞り込み（1day・1week）。追加フォームでは、これまで使ったカテゴリをワンタップで選択可能
- 追加・完了・削除は、画面を先に更新する「楽観的UI更新」で、待ち時間なく操作可能
- 完了済み課題のまとめて削除
- スマホ表示に対応。ホーム画面にアプリとして追加可能（PWA対応）

### 1dayモード

- 0〜24時の時間軸に、開始時刻の位置で課題を配置
- 終了時刻の指定に応じて、ブロックの高さが変わる（「終了未定」も選択可能）
- 時間帯が重なった課題は、横に並べて表示
- 現在時刻を示す赤い線と、現在時刻付近への自動スクロール
- 時刻を決めない課題は、「いつでもやる」欄に優先度順で表示
- 今日の完了率の表示
- 完了済み課題の一覧表示（未完了に戻す・削除が可能）

### 1weekモード

- 締切日・優先度・カテゴリの設定と、課題の編集
- 締切日は、「今日／明日／3日後／1週間後」のボタンで選択でき、曜日と残り日数も表示
- 締切間近（3日以内）の課題を自動でハイライト表示
- 今週の予定入力（曜日ごと・体調、ユーザーごとにSupabaseへ保存）
- AIによるスケジュールアドバイス
- 課題のフィルタリング（すべて／未完了／完了済み）

### 1monthモード

- 月のカレンダー表示。日付ごとの未完了件数を表示し、今日と選択中の日付を強調
- 「◀ ▶」で前の月・次の月へ移動、「今月」ボタンで現在の月に戻る
- 日付をタップすると、その日の課題を一覧表示（完了・編集・削除が可能）
- 1week・1dayの課題も統合して表示（1weekは締切日、1dayは作成日の位置）。課題ごとに、日・週・月のバッジで区別
- 「＋」ボタンから、選択中の日付を初期値にして課題を追加
- 表示中の月の完了済み課題を、まとめて削除

## 使用技術

| 技術                              | 用途                        |
| --------------------------------- | ------------------------- |
| HTML / CSS / JavaScript           | フロントエンド                |
| Google Fonts（Noto Sans JP）      | 日本語フォント                |
| Groq API（openai/gpt-oss-120b）   | AIアドバイス機能              |
| Cloudflare Workers                | APIキーの安全な管理・認証確認・DBアクセスの仲介（`/api/*`） |
| Supabase Auth                     | ユーザー認証（サインアップ・ログイン） |
| Supabase                          | タスク・予定データの保存・管理（Row Level Securityでユーザーごとに分離） |
| Cloudflare（Workers Static Assets） | ホスティング・自動デプロイ（GitHubのpushで反映） |

## 構成

```

worker/index.js  APIをまとめたCloudflare Worker（/api/*）
wrangler.jsonc   Cloudflareの設定
```

## 工夫した点

- **AIアドバイス機能**：未完了のタスクと今週の予定・体調をもとに、AIが具体的なスケジュールを提案します。単なるタスク管理にとどまらず、ユーザーの状況に合わせた提案ができる点が特徴です。
- **セキュアな実装**：APIキーをフロントエンドに直接書かず、Cloudflare Workerのサーバーサイドで管理しています。キーはCloudflareの管理画面にだけ登録し、GitHubには置きません。AIアドバイスを含むすべてのAPI（`/api/*`）でログイン（トークンの検証）を必須にし、AIに送る入力も形式と長さをチェックしています。
- **ユーザーごとのデータ分離**：Supabase Authでログイン機能を実装し、Worker側で検証したユーザーIDによって、必ずデータを絞り込んでいます。さらにテーブルにはRow Level Security（RLS）を設定し、公開用キーによる直接アクセスからも他人のタスク・予定が見えないようにしました。
- **データの永続化**：タスク・予定データをlocalStorageからSupabaseに移行し、デバイスをまたいでも同じアカウントで同じデータにアクセスできる構成にしました。
- **モードの分離と統合**：`tasks`テーブルに`mode`カラム（`day`／`week`／`month`）を追加し、モードごとに課題・統計・画面を分けました。テーブルやAPIを複製せずに済むため、保守しやすい構成です。1monthモードは、同じテーブルの全モードの課題を日付で集めて表示するため、新しいテーブルやAPIを追加せずに実現できました。
- **カレンダーの日付処理**：日付を`toISOString()`（UTC基準）で文字列にすると、日本時間では1日ずれることがあります。そこで、年・月・日から直接文字列を組み立てる関数を用意し、日付のずれを防いでいます。
- **時間軸の表示**：開始・終了時刻から、課題ブロックの位置と高さを計算して配置しています。時間が重なる課題は、カレンダーアプリと同じように、重なりをまとめて列に割り当て、横並びで表示します。
- **体感速度の改善**：課題の追加・完了・削除のたびに全件を取得し直していたため待ち時間が出ていました。画面を先に更新し、保存は裏側で行う方式に変え、保存に失敗したときは元の状態に戻すようにしました。
- **端末ごとの表示崩れへの対応**：LINE内蔵ブラウザで、標準の時刻入力が崩れて見えなくなる問題が起きました。CSSの調整では直らなかったため、時・分のプルダウンに置き換え、どの環境でも同じ見た目・操作になるようにしました。
