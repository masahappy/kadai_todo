# AIToDo

AIを活用したタスク管理アプリです。

## 概要

AITodoは、日々のタスクを効率的に管理するためのWebアプリケーションです。
未完了のタスクと今週の予定を入力すると、AIが効率的なスケジュールを提案してくれます。
ログイン機能により、ユーザーごとにタスク・予定を管理できます。

## 機能

- メールアドレス／パスワードによるログイン・新規登録・ログアウト
- タスクの追加・削除・完了管理（ユーザーごとにSupabaseへ永続化）
- 締切日・優先度・カテゴリの設定
- 締切間近（3日以内）のタスクを自動でハイライト表示
- 今週の予定入力（曜日ごと・体調、ユーザーごとにSupabaseへ保存）
- AIによるスケジュールアドバイス
- タスクのフィルタリング（すべて／未完了／完了済み）

## 使用技術

| 技術                              | 用途                        |
| --------------------------------- | ------------------------- |
| HTML / CSS / JavaScript           | フロントエンド                |
| Groq API（openai/gpt-oss-120b）   | AIアドバイス機能              |
| Netlify Functions                 | APIキーの安全な管理・認証確認・DBアクセスの仲介 |
| Supabase Auth                     | ユーザー認証（サインアップ・ログイン） |
| Supabase                          | タスク・予定データの保存・管理（Row Level Securityでユーザーごとに分離） |
| Netlify                           | ホスティング・デプロイ         |

## 工夫した点

- **AIアドバイス機能**：未完了のタスクと今週の予定・体調をもとに、AIが具体的なスケジュールを提案します。単なるタスク管理にとどまらず、ユーザーの状況に合わせた提案ができる点が特徴です。
- **セキュアな実装**：APIキーをフロントエンドに直接書かず、Netlify Functionsを用いてサーバーサイドで安全に管理しています。
- **ユーザーごとのデータ分離**：Supabase Authでログイン機能を実装し、`user_id`とRow Level Security（RLS）により、他人のタスク・予定が一切見えない設計にしました。データベース側にも安全装置を設け、アプリのコード側のミスに対しても二重に守られる構成です。
- **データの永続化**：タスク・予定データをlocalStorageからSupabaseに移行し、デバイスをまたいでも同じアカウントで同じデータにアクセスできる構成にしました。

## 苦労した点

- AIの実装にあたっての試行錯誤。APIキーの安全な管理方法や、利用モデルの廃止（Groqのモデル廃止）への対応など、多くの課題を一つひとつ解決しながら開発を進めました。
- localStorageからSupabaseへのデータ移行に伴う、CRUD処理の全面的な書き換え。
- ログイン機能の導入に伴い、Netlify Functions側でユーザーの認証トークンを検証する共通処理を新たに設計し、既存の全APIエンドポイントに組み込む必要がありました。
